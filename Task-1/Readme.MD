# LUMÉ — Interior Design Studio

A premium interior design website created as part of my AUSPI internship project.

LUMÉ focuses on creating a refined, editorial-style digital experience for an interior design studio, combining elegant typography, immersive imagery, smooth animations, and a warm neutral visual identity.

## Overview

LUMÉ is designed around the idea that an interior is more than just a space — it is a feeling.

The website presents:

- Interior design studio introduction
- Selected spaces and projects
- Design approach
- Contact call-to-action
- Responsive navigation
- Smooth scroll-based animations
- Editorial typography and image compositions

## Design Direction

The visual identity follows a Modern Atelier aesthetic:

- Warm Beige — #F5EBE6
- Obsidian Black — #1E1E1E
- Muted Rose/Taupe — #C8B0A6

### Typography

- Cormorant Garamond — Display / editorial typography
- Inter — Body and UI typography

## Built With

- HTML5
- CSS3
- JavaScript
- GSAP
- Google Fonts

## Features

- Responsive layout
- Smooth section transitions
- Scroll-based text animations
- Interactive navigation
- Image hover effects
- Editorial-style layouts
- Responsive mobile menu
- Modern interior-design focused UI

## Responsive Design

The website is designed to adapt across desktop, tablet, and mobile screens, with attention to typography, spacing, image composition, and navigation.
